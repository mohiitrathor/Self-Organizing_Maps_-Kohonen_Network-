# Customer Segmentation using Self-Organizing Maps (SOM)

This project uses Self-Organizing Maps (SOM), an unsupervised neural network technique, to segment customers and discover hidden patterns in data.

---

## Overview

The goal of this project is to cluster customers based on their features without using labeled data, enabling pattern discovery and anomaly detection.

---

## Model Used

* Self-Organizing Maps (Kohonen Networks)
* Unsupervised Learning

---

## Tech Stack

* Python
* NumPy
* Matplotlib
* MiniSom (or equivalent SOM implementation)

---

## Workflow

1. Data preprocessing & normalization
2. Training SOM model
3. Visualizing distance map (U-Matrix)
4. Identifying clusters & anomalies

---

## Results

* Successfully grouped customers into distinct segments
* Visualized clusters using SOM distance map
* Highlighted potential outliers/anomalies

---

## Key Learnings

* Understanding unsupervised learning
* Clustering using neural networks
* Visual interpretation of SOM outputs
